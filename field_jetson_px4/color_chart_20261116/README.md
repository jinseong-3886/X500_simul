# 색상표 인쇄 안내 (2026-11-16)

> 대상: 인쇄소 방문용 + 팀 기록

## 파일
- **`flytrap_color_chart_A3.pdf`** ← 인쇄소에 줄 파일 (A3 420×297mm, 300dpi, 무손실)
- `flytrap_color_chart_A3.png` — 같은 내용 이미지 (PDF가 안 될 때)
- `flytrap_color_chart_layout.json` — 각 칸의 위치·원래 색 (분석용, 인쇄 X)
- `make_color_chart.py` — 생성 스크립트

## 무엇에 쓰나
인쇄하면 화면 색과 다르게 찍혀서 패치가 작동하지 않았음(2026-11-13 테스트). 이 색상표를 **최종 보드와 같은 프린터·종이**로 인쇄해 D435i로 찍으면 "원래 색 → 인쇄 후 카메라에 보이는 색" 변환표를 만들 수 있고, 그걸 넣어서 패치를 다시 학습함.
- 칸 242개 = RGB 기본색 125 + 회색 17 + **패치에 실제로 쓰인 색 80** + 버스 색 20
- 네 모서리 검은 마커 = 사진에서 색상표 위치를 자동으로 찾는 용도 (자르면 안 됨)

## 인쇄소에 전할 말
1. **A3, 100% 실제 크기로** 출력 (확대·축소·여백 맞춤 X). 아래 검은 막대가 정확히 10cm여야 함.
2. **색 보정·자동 보정 끄고 원본 그대로** 출력 (색 관리 OFF).
3. **무광(매트) 용지.**
4. **나중에 A2 보드(폼보드 부착)를 같은 프린터·같은 종이로 맡길 예정**이라고 말하고, 그때도 같은 장비로 가능한지 확인. → 색상표가 의미 있으려면 최종 출력과 같은 장비여야 함.
5. 가능하면 **사용한 프린터 기종과 용지 이름**을 메모해 오기.

## 보드 크기 (확정값, 시뮬과 동일)
- 그림 크기 **59.4 × 39.6 cm** (가로 = A2 가로, 버스 그림 비율 3:2) → **A2 용지(59.4×42.0)**에 위아래 1.2cm 여백으로 출력
- **폼보드**에 붙여 세움, **보드 중심 높이 1.0m**, 이륙 지점에서 **2.5m**
- 미션 옵션 `--tgt-h 0.396` (= 그림 높이 39.6cm)
- 깨끗한 보드 + 패치 보드 2장. **패치는 재학습 후** 주문 (지금 패치는 인쇄 시 작동 안 함)
